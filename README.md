# API de Receitas

Boas-vindas ao repositório do projeto API de Receitas

<details>
<summary><strong>🧑‍💻 O que foi desenvolvido</strong></summary>

Foi desenvolvido um aplicativo de Receitas que está totalmente funcional 😉.
cria uma **api de receitas** que vai retornar todas as receitas disponíveis, adicionar, remover e atualizar as mesmas. Além disso, é possível cadastrar, remover, consultar e atualizar dados de usuários do app e permitir o cadastro e consulta de comentários nessas receitas.

essa api de receitas com ASP.NET. Todos os services com os modelos de dados já estão disponíveis.

</details>
  
<details>
  <summary><strong>📝 Habilidades que foram trabalhadas </strong></summary>

Neste projeto, exercitei os conceitos:

- Entender do funcionamento do ASP.NET e como ele se integra ao C#.
- Entender da arquitetura MVC.
- Criar controllers que recebam dados pelo corpo e pela URL da requisição.
- Lançar códigos de retorno que respeitem o padrão do HTTP Status Code.


</details>

<details>
  <summary><strong>‼️ como executar o projeto</strong></summary><br />

  1. Clone o repositório

  - Use o comando: `git clone git@github.com:tryber/csharp-001-projeto-api-de-receitas.git`.
  - Entre na pasta do repositório que você acabou de clonar:
    - `cd csharp-001-projeto-api-de-receitas`

  2. Instale as dependências
  
  - Entre na pasta `src/`.
  - Execute o comando: `dotnet restore`.
  
  3. executar o projeto
  - ```bash
    dotnet run
